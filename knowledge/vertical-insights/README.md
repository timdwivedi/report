# Vertical Insights

Per-vertical learnings. Create a new file for each vertical after 3+ builds.

## Naming Convention

`{vertical-slug}.md` — e.g., `saas.md`, `coaching.md`, `ecommerce.md`

## When to Create

After completing 3+ builds in the same vertical, create a dedicated file summarizing:
- Common pain points for this vertical
- Preferred tech stack / integrations
- Typical feature set
- Design preferences and patterns
- Pricing norms
- Gotchas and pitfalls
