# Agent 6.5 — Critique Examples Reference

> These are example critique formats for each of the 8 categories. Reference these for style and depth, but always write about THIS specific build.

---

## 1. Big Idea / Positioning — Example

```markdown
**1. The "Unique Mechanism" Isn't Unique**
- **What's weak:** The spec says the unique mechanism is "AI-powered lead scoring." But that's table stakes in 2026. Every CRM has AI scoring. This isn't a mechanism — it's a feature.
- **Why it hurts:** Customers can't articulate why YOU vs. competitor. Undifferentiated = price war = margin compression.
- **What Hormozi would do:** Find the ONE THING this app does that competitors CAN'T or WON'T do. Name it: 'Clone-a-Rep AI.' Now you have a story, not a feature list.
```

## 2. Offer Clarity — Example

```markdown
**2. The Hero Headline Is Generic**
- **What's weak:** Homepage headline: "The smarter way to manage your pipeline." This could be ANY CRM. Zero specificity.
- **Why it hurts:** You have 3 seconds before the visitor bounces. Generic = ignored. Specificity = interest.
- **What Hormozi would do:** Use RESULT + TIME + WITHOUT formula:
  - ❌ "The smarter way to manage your pipeline"
  - ✅ "Close 3x more deals in 30 days without hiring more reps"
```

## 3. Value Ladder — Example

```markdown
**3. No Lead Magnet = Leaving Money on the Table**
- **What's weak:** The only CTA is "Start Free Trial." No lead magnet. No reason for a cold visitor to engage if they're not ready to buy TODAY.
- **Why it hurts:** 97% of visitors aren't ready to buy now. You're optimizing for 3% and ignoring 97%.
- **What Hormozi would do:** Build a lead magnet that solves ONE micro-problem:
  - "Free Cold Email Scorecard — See why your emails aren't getting replies in 60 seconds"
  - Gate it with email. Now you have a list. Now you can nurture.
```

## 4. Conversion Path — Example

```markdown
**4. Testimonials Are Weak — No Metrics**
- **What's weak:** Testimonials section: "Great tool, very helpful!" — Sarah K. No proof. No outcome. No credibility.
- **Why it hurts:** Testimonials without metrics are just words. Words don't sell. Results sell.
- **What Hormozi would do:** Rewrite EVERY testimonial with a METRIC:
  - ❌ "Great tool, very helpful!"
  - ✅ "We closed $47K in our first 30 days using this." — Sarah K., Agency Owner, Chicago
```

## 5. Onboarding / Activation — Example

```markdown
**5. No Engineered "Aha Moment" — Users Churn Before They See Value**
- **What's weak:** After signup, the user sees an empty dashboard. No onboarding. No checklist. No quick win.
- **Why it hurts:** If a user doesn't get value in the first session, they churn.
- **What Hormozi would do:** Force a micro-win in < 5 minutes:
  - On signup: "Let's get you your first lead in 90 seconds."
  - Auto-populate 1 demo lead with a pre-written DM
  - User clicks "Send Demo DM" → gets instant feedback
```

## 6. Pricing / Monetization — Example

```markdown
**6. Pricing Is Cost-Plus, Not Value-Based**
- **What's weak:** $49/mo for 100 leads, $99/mo for 500 leads. Feature-based pricing. Doesn't tie to OUTCOME.
- **Why it hurts:** A customer who closes $100K/mo from your leads would happily pay $1K/mo. You're charging $99.
- **What Hormozi would do:** Anchor on OUTCOME, not input:
  - ❌ "$99/mo for 500 leads"
  - ✅ "$99/mo for your first $10K in closed deals. After that, 5% of revenue generated."
```

## 7. Marketing Engine — Example

```markdown
**7. No Built-In Virality — Growth is 100% Linear**
- **What's weak:** No referral program. No share mechanics. Growth is 100% top-of-funnel spend.
- **Why it hurts:** Linear growth = expensive growth. If CAC > LTV, you're dead.
- **What Hormozi would do:** Build a selfish referral loop:
  - "Invite 3 teammates → unlock the Pro feature for free"
  - Now users recruit FOR you. Now CAC drops. Now growth compounds.
```

## 8. Moat — Example

```markdown
**8. No Moat — This is a Feature, Not a Company**
- **What's weak:** The core value prop is "AI writes your DMs." That's a feature any CRM can add in a sprint.
- **Why it hurts:** If your only advantage is a feature, you're in a race to zero margin.
- **What Hormozi would do:** Build a DATA moat:
  - Every DM sent trains the AI on what works for THAT industry
  - After 10K DMs, your AI knows which openers get 40% reply rates in SaaS sales
  - Now competitors can't just "build the feature" — they need the DATA.
```
