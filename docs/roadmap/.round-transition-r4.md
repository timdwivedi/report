### Round 4 (Product Experience — 16 steps, 5 phases)

**Phase A — Foundation (Mechanic):**
1. **LineItemAddOn Restructure** — Added `id`, `sale_price_per_unit`, `level: 'product' | 'location'`, `decoration_id?`. Backward-compatible with existing add-ons.
2. **quantities_received** — Boolean on `ProjectLineItem`, pairs with `art_received` for Ready/Draft badge.
3. **ProductColor Images** — `images?: { url: string; is_primary: boolean }[]` on ProductColor. Multi-image per color variant.
4. **ProductDecorationLocation** — New interface: `id`, `location_name`, `placeholder_run_charge`, `placeholder_setup_charge`. Added `decoration_locations?` on Product.
5. **ScrapedProductData** — New interface for AI product scraper pipeline: source_url, product_name, description, images, colors, sizes, specs, supplier info.
6. **AddOnLevel Type** — `'product' | 'location'` union type.
7. **DECORATION_LOCATION_PRESETS** — 11 location presets (Front Chest, Full Front, Full Back, etc.)
8. **Dual-Level Quoting** — `calculateLineItem()` now filters add-ons by `level` property.
9. **Product Scrape API** — `POST /api/products/scrape` returns mock ScrapedProductData by URL domain.
10. **Demo Data Updates** — All add-ons have `id`/`level`/`sale_price_per_unit`. Location-level add-on examples. `decoration_locations` on 2-3 products. Color images. `quantities_received` on all line items.

**Phase B — AI Product Assistant (Tailor):**
1. **ProductScrapeReview (NEW)** — Full review form: editable name/description, image grid with include/exclude, colors with hex swatches, sizes as toggle pills, pricing section (contract tiers vs all-in), category, "Publish to Catalog" action. Violet/purple AI accent. Portal-rendered.
2. **Products Page AI Import Mode** — Three-mode "Add Product" flow: Quick Entry vs AI Import. URL input → scrape API → loading state → ProductScrapeReview modal → publish to catalog.

**Phase C — Products & Add-Ons Enhancements (Tailor):**
1. **Multi-Image Per Color** — ProductEditModal Variants tab: up to 5 images per color, primary designation, thumbnails, remove action.
2. **Decoration Locations Tab** — Template locations from DECORATION_LOCATION_PRESETS dropdown or custom text. Placeholder run/setup charges per location.
3. **Dual-Level Add-Ons** — ProductDetailPanel split into Product Add-Ons (name, cost, sale price) and Location Add-Ons (location dropdown, name, cost, sale price). Both wire into pricing grid.
4. **Quantities Received Checkbox** — Pairs with art_received. Both checked = "Ready" badge. Either unchecked = "Draft" badge.

**Phase D — Creative Standalone Page (Tailor):**
1. **Creative Page (NEW)** — `/dashboard/creative` aggregates all creative requests across all projects. Search, status filter, type filter. Click row opens CreativeRequestDetailPanel.
2. **Sidebar Navigation** — "Creative" link with Palette icon added to DashboardLayout nav.

**Phase E — Shipping Address (Tailor):**
