- `lib/demo/demo-data-provider.ts` — Primary system using `app.ts` types (kebab-case statuses)

## Known Issues (Not Fixed — Documented for Future)

### Architecture
1. **Dual type systems** — `types/app.ts` (kebab-case) and `types/brandops.ts` (Title Case) define the same domain types with incompatible values. Should consolidate to one.
2. **Dual demo data systems** — `demo-data-provider.ts` and `demo-data.ts` are parallel implementations. The barrel export uses the provider version.
3. **Triple-redundant label maps** — `constants/app.ts`, `demo-data-provider.ts`, and `demo/label-maps.ts` all define status labels/styles.

### Dashboard Pages
4. **7 stub pages** — Projects, Clients, Orders, Commissions, Programs, Analytics, and Settings are placeholder stubs. Components exist (KanbanBoard, DataTable, StatCard) but aren't wired to these pages yet.
5. **Quick action links** — Several quick actions point to routes that don't exist (`/dashboard/settings/matrices`, `/dashboard/projects/new`, `/dashboard/clients/new`, `/dashboard/quote`).

### Styling
6. **Shared components use dark theme classes** — `ActionButton`, `ClickReveal`, `LoadingSequence` use `dark-*` color utilities that clash with BrandOps' light enterprise theme.
7. **Missing Creative Brief Layer 4 elements** — Section headings missing `text-gradient-headline` class; no section dividers between landing page sections; no `noise-overlay` on landing page `<main>`.
8. **`transition-all` used throughout** — Should be specific properties, though Creative Brief does specify this pattern.
9. **Glow shadow uses green** — `boxShadow.glow` in Tailwind config uses green rgba instead of blue per Creative Brief.

### Accessibility
10. **Missing mobile hamburger menu on Header** — Landing page nav hidden on mobile with no toggle.
11. **Slider inputs on Calculator** — Labels not connected via `htmlFor`/`id`.
12. **Password toggle buttons** — Missing aria-labels on auth pages.

### Code Quality
13. **`catch (err: any)`** — Auth pages should use `unknown` instead.
14. **`process.env.X!` assertions** — Auth callback and Stripe webhook routes crash in demo mode.
15. **Supabase client recreation** — `createClient()` called in component body (AuthProvider, OrgContextProvider, auth pages).
16. **GBP (£) in code comments** — Type definitions reference pounds; should be USD ($) per project rules.
